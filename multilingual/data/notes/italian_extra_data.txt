ITALIAN EXTRA DATA — NOTES FOR PREPROCESSING / TRAINING

We have three main Italian extra-data sources:

1. italian_civil_code
Processed file:
  multilingual/data/processed/italian_civil_code/...

Content:
  - LLM-generated MCQs from articles of the Italian Civil Code.
  - Each example is based on an article_id, article_title, and article_text.
  - The final examples are already in the standard MCQ format:
      prompt with A), B), C), D)
      answer as a letter
      metadata with article_id and article_title
  - The examples also include generation/verification metadata.
  - The examples inspected have clean formatting and valid answer labels.

Usefulness:
  - High-value Italian legal-domain data.
  - Strongly relevant for Italian country-specific/legal knowledge.
  - More focused than Polizia general knowledge.
  - Complementary to Quaderno, especially for civil-law concepts.

Caveat:
  - These examples are LLM-generated, not directly extracted from public exam PDFs.
  - They should be included, but should not dominate the Italian mix.
  - Because they are generated from source articles, they may be more synthetic/simple than exam-style questions.

Recommended priority:
  - High priority, but cap moderately.
  - Useful cap range: 500–1500 examples depending on how much Italian legal data is needed.

2. quaderno_prefettizia
Raw file:
  multilingual/data/raw/quaderno_prefettizia/quaderno_prefettizia_parsed.jsonl

Processed outputs:
  multilingual/data/processed/quaderno_prefettizia_clean/quaderno_prefettizia_clean.jsonl
  multilingual/data/processed/quaderno_prefettizia_clean/quaderno_prefettizia_economia_politica_clean.jsonl

Subsets:
  A. quaderno_prefettizia_clean
     - Keeps:
       DIRITTO COMUNITARIO
       DIRITTO COSTITUZIONALE
       DIRITTO AMMINISTRATIVO
       DIRITTO CIVILE
     - High-priority dataset.
     - Strongly relevant for Italian / EU civic, legal, constitutional, administrative, and institutional knowledge.
     - Best aligned with regional/country-specific Italian knowledge.
     - Should be included with a relatively high cap.

  B. quaderno_prefettizia_economia_politica_clean
     - Keeps:
       ECONOMIA POLITICA
     - Saved separately because it is less directly aligned with the main legal/civic objective.
     - Mixed content:
       generic micro/macro economics
       Italian economic history
       Italian political history
       ISTAT / labor-market concepts
       European/international institutions and historical events
     - Useful as auxiliary Italian knowledge, but lower priority than the main Quaderno legal/civic subset.
     - Include with a moderate/low cap, e.g. 500–1000 examples depending on total Italian data needs.

Important cleaning notes for Quaderno:
  - Section names include difficulty suffixes, e.g.:
      DIRITTO AMMINISTRATIVO - DIFFICOLTA' MEDIA
    so section filtering must use section_base = text before " - DIFFICOLTA".
  - Remove page artifacts such as:
      Pagina 274
      Pagina 331
      Pagina 545
  - Keep 3-option questions if valid, but require contiguous labels from A onward.
  - Drop malformed examples with non-contiguous options or corrupted option labels.

3. polizia_di_stato
Raw file:
  multilingual/data/raw/polizia_di_stato/polizia_di_stato_parsed.jsonl

Processed output:
  multilingual/data/processed/polizia_di_stato_clean/polizia_di_stato_clean.jsonl

Subsets:
  A. section = None / NaN
     - Keep.
     - This is the useful part.
     - Mostly Italian general-knowledge MCQs:
       science
       geography
       grammar
       history/current affairs
       basic civic/world knowledge
     - Not strongly regional, but useful as auxiliary Italian MCQ data.
     - Treat as region_agnostic / general_knowledge.
     - Include with a low/moderate cap, e.g. around 500 examples unless more Italian volume is needed.

  B. INGLESE
     - Drop.
     - English-completion questions, not useful for Italian regional/general knowledge.
     - Also visibly noisy due to PDF artifacts.

  C. MATEMATICA
     - Drop.
     - Generic arithmetic/calculation questions.
     - Not aligned with regional/cultural/civic objective.
     - Also contains some option corruption.

Important cleaning notes for Polizia:
  - In pandas, the kept section appears as NaN, but in records it is actually section = None.
  - The safest filter is:
      section is None
  - Some parsed examples had corrupted option order like:
      D) Los Angeles BB) New York
    These should be dropped, not kept.
  - Require contiguous option labels from A onward.
  - Keep valid 3-option questions, but drop A/C/D or A/D/E malformed examples.

Training priority:
  1. quaderno_prefettizia_clean
     highest priority among these sources; public-exam civic/legal data

  2. italian_civil_code
     high priority legal data, but synthetic/LLM-generated; cap moderately

  3. quaderno_prefettizia_economia_politica_clean
     auxiliary Italian political/economic/history data; moderate-low cap

  4. polizia_di_stato_clean
     auxiliary general Italian MCQ data; low/moderate cap

Recommended rough caps:
  quaderno_prefettizia_clean: 2000–3000
  italian_civil_code: 500–1500
  quaderno_prefettizia_economia_politica_clean: 500–1000
  polizia_di_stato_clean: 500–1000

Main principle:
  Use Quaderno legal/civic data as the strongest Italian regional/country-specific signal.
  Use Italian Civil Code as high-quality legal-domain support, but remember it is generated rather than directly exam-parsed.
  Use Economia Politica and Polizia only as auxiliary Italian-language MCQ data, not as the core regional signal.
