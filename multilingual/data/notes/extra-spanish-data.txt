SPANISH-SPEAKING REGIONAL DATA SOURCES — PREPROCESSING AND TEACHER MCQ GENERATION HANDOFF

Project context:
We are fine-tuning a multilingual MCQ model for regional/country-specific knowledge. The goal here is to build additional Spanish-language source datasets from Spain and Argentina. Most of these sources are not already MCQ datasets. The intended pipeline is:

1. Parse each source into clean, well-defined source units.
2. For each source unit, call a teacher model to generate a 4-option MCQ.
3. Call a verifier teacher model on the generated MCQ.
4. Keep only MCQs that pass strict validation.

Core rule:
Never pass an entire PDF to the teacher model. Each teacher call should receive one clean source unit with enough local context:
  - source name
  - country / region
  - title / chapter / section context
  - one article or one FAQ/Q&A pair
  - source text

The teacher should generate one MCQ per source unit, or skip the unit if it is not suitable.

Recommended final MCQ format:
{
  "id": "...",
  "dataset": "...",
  "language": "spanish",
  "split": "all",
  "task_type": "mcq",
  "prompt": "Question...\n\nA) ...\nB) ...\nC) ...\nD) ...",
  "answer": "B",
  "metadata": {
    "country": "...",
    "region": "...",
    "source": "...",
    "source_url": "...",
    "license": "...",
    "source_unit_type": "...",
    "source_unit_id": "...",
    ...
  },
  "source_id": "..."
}

Recommended teacher generation format:
Input to teacher:
  - source metadata
  - source context
  - source text
  - instruction to generate exactly one 4-option MCQ in Spanish

Output from teacher:
  - question
  - A/B/C/D options
  - gold answer letter
  - short explanation / evidence span if useful for validation

Recommended verifier format:
Input to verifier:
  - original source text
  - generated question
  - options
  - gold answer

Verifier must check:
  1. The gold answer is directly supported by the source.
  2. Exactly one option is correct.
  3. Distractors are clearly wrong or clearly less correct.
  4. The question is answerable from the source unit alone.
  5. The MCQ does not distort the legal or institutional meaning.
  6. There is no answer leakage.
  7. The question is not overly vague.
  8. The source unit has enough information to justify the answer.

Verifier output should be strict:
  VALID
or:
  INVALID: <short reason>
