MERA DISTILLATION DECISIONS
============================

Dataset: MERA (Russian benchmark, multiple subsets)
Goal: distill teacher rationales for high-quality Russian MCQ examples

SUBSET DECISIONS
----------------

mamuramu (285 examples) → DISTILL ALL
  Russian MMLU-style MCQ covering law, medicine, psychology, business ethics,
  politics, clinical knowledge. Exactly INCLUDE-style regional/professional
  knowledge. Small pool so distill everything. High priority.

mathlogicqa (680 examples) → DISTILL ALL, use ~300-400 in final SFT mix
  Russian math/logic word problems (algebraic equations, arithmetic reasoning).
  Not regional knowledge, but useful for general Russian reasoning.
  Qwen3.5-27B will get nearly 100% correct → high confidence rationales.
  CoT traces will be short and genuinely informative ("if 3z-5=4, then z=3").
  Keep separate from regional distillations. Cap at 300-400 in final dataset
  to avoid over-indexing on math given the adapter's focus is regional MCQ.

ruopenbookqa (2338 examples) → SKIP
  Translated US elementary science MCQ (not Russian-regional knowledge).
  Examples: "seeds need to spread", "rubber protects from electricity".
  No CoT rationale from a teacher model adds regional value here.
  The answers are often obvious so rationales would be trivial.

ruworldtree (115 examples) → SKIP
  Same issue as ruopenbookqa — these are NYSED/MCAS US school exams
  translated to Russian. Not Russian cultural or regional knowledge.
  Also too small (115 examples) to be worth the API budget.

parus (400 train + 100 val) → SKIP
  Two-option A/B causal commonsense ("what caused the situation?").
  Not regional knowledge. Already set to 0 in builder config.
  Format mismatch with 4-option MCQ target.

IMPLEMENTATION NOTE
-------------------
The distillation script should filter MERA by subset before processing:
  - Read the MERA per-dataset JSONL files
  - Filter to subset == "mamuramu" for regional distillation
  - Filter to subset == "mathlogicqa" for math distillation
  - Run them as separate distillation jobs with separate output files

No need to add regionality labels to MERA — the subset field already
distinguishes regional (mamuramu) from non-regional (ruopenbookqa etc.).
