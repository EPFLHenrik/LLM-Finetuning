# Assets

Contains chat template assets used by the multilingual pipeline.

Files
- `chat_template.jinja`: base chat prompt template.
- `chat_template_multilingual-thinking.jinja`: reasoning-enabled multilingual prompt.
- `chat_template_multilingual-nonthinking.jinja`: direct-answer prompt without explicit thought traces.
- `chat_template_multilingual-augmented.jinja`: augmented prompt used for some data generation or evaluation paths.

These are repository assets for prompt formatting, not model weights or training data.
